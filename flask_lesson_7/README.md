# Lesson 7: Your creative command centre

**Students: open [LESSON_7.md](LESSON_7.md).**

A complete Flask project with a locally bundled AdminLTE 4.0.0 dashboard. No npm, CDN requests, Git, or student GitHub accounts are needed. Flask must already be installed, or installed once while online.

- [Student lesson](LESSON_7.md)

- [Asset versions and licences](static/vendor/ASSETS.md)

Run from this folder with your Python environment active:

```bash
python -m flask --app app run --debug
```

Open http://127.0.0.1:5000/static/dashboard.html . The Lesson 6 page remains at http://127.0.0.1:5000/static/index.html .

This is a classroom interface template, with a working random generator. It is not an authenticated administration system. Run locally.
