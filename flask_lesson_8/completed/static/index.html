How do I create an item?

Enter an invented nickname, choose a colour, and press Forge my item.

Does my colour change the item?

No. It changes the result card. Python chooses the item randomly.

What happens to my nickname?

This application uses it in the browser to personalise the result. Its code does not send the nickname to Python or save it.
