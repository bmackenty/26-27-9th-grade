Field guide: what is really happening?

Which part is the back end?

Python and Flask run in your terminal. GET /api/generate returns JSON containing an item. The browser fetches it.

What does AdminLTE do?

It supplies front-end styles and interface behaviour. It does not create accounts, save items, or provide admin permissions.

Does this work without internet?

After the files and Flask are installed, this dashboard uses local assets and a local Flask server. Keep Flask running.
